About and limitations

  • The model predicts the next Red List category, not extinction itself.
  • It uses only the current status and taxonomic group; it cannot assess a species from its name alone.
  • Training data contain only species whose category changed, so predictions assume a change occurs.
  • Threat factors shown for EN and CR species are informational and are not model inputs.
  • Use as an exploratory tool. Official status comes from iucnredlist.org.
